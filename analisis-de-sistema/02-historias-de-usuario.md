# Historias de usuario

**Formato:** Como [actor], quiero [acción], para [beneficio].

| ID | Historia de usuario |
|---|---|
| HU01 | Como administrado, quiero responder tres preguntas, para saber qué licencia me corresponde, qué documentos presentar, cuánto pago y cuánto demora. |
| HU02 | Como administrado, quiero llenar un formulario que solo me pida los documentos de mi licencia, para no presentar requisitos innecesarios. |
| HU03 | Como administrado, quiero conocer automáticamente el monto de la tasa, para pagar lo correcto según el TUPA vigente. |
| HU04 | Como administrado, quiero pagar en línea sin riesgo de que me cobren dos veces, para no tener que ir a la caja. |
| HU05 | Como administrado, quiero consultar el estado de mi trámite con mi número de expediente o DNI/RUC desde el celular, para no hacer colas. |
| HU06 | Como administrado, quiero recibir mi licencia digital con código QR, para demostrar su validez en cualquier momento. |
| HU07 | Como evaluador, quiero revisar el expediente y confirmar el nivel de riesgo, para aprobarlo u observarlo correctamente. |
| HU08 | Como inspector ITSE, quiero registrar el resultado de la inspección con fotos aunque no tenga señal, para no perder información en campo. |
| HU09 | Como jefatura, quiero recibir alertas antes de que venza un plazo, para cumplir los plazos del TUPA. |
| HU10 | Como jefatura, quiero ver un tablero con trámites, tiempos de atención e ingresos, para tomar decisiones. |
| HU11 | Como administrador funcional, quiero crear una nueva versión de una licencia cuando cambie el TUPA, para actualizar el sistema sin reprogramarlo. |
| HU12 | Como administrado, quiero recibir un aviso antes de que venza mi certificado ITSE, para renovarlo a tiempo. |
| HU13 | Como administrado, quiero solicitar transferencia, cambio de giro o duplicado de mi licencia, para mantenerla actualizada. |
| HU14 | Como administrado, quiero presentar un recurso de reconsideración o apelación, para defender mis derechos. |
