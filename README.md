
# Sistema de Trámite de Licencias de Funcionamiento – Municipalidad Provincial de Huanta

## Estudiante
Sulca Ccorimanya, Jeimy Gregori – Código 27190105

## Descripción
Propuesta de arquitectura de software para digitalizar el trámite de las nueve
licencias de funcionamiento del TUPA 2024 de la Municipalidad Provincial de Huanta.

## Idea central
**Un motor, nueve recetas:** un solo motor de trámites y un catálogo versionado con las
nueve licencias (requisitos, tasa, plazo, calificación, orden del ITSE y vigencia).

## Estructura del repositorio
- `analisis-de-sistema/`: actores, historias de usuario, requisitos, atributos de calidad, restricciones y drivers.
- `arquitectura/`: arquitectura inicial y diagramas.
