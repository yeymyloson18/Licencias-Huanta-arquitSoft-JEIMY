# Cuestionario de usabilidad SUS (EQ-05)

El SUS (*System Usability Scale*) son 10 afirmaciones que cada persona califica del 1 (totalmente en
desacuerdo) al 5 (totalmente de acuerdo). Da un puntaje de 0 a 100. Un sistema se considera usable por
encima de 68.

## Cómo aplicarlo a 5 personas

1. **Quiénes**: 5 personas que nunca hicieron el trámite. Si es posible, de distintas edades y con
   celular propio.
2. **Tarea** (la misma para todas, sin ayuda): "Usted quiere abrir una bodega en su vivienda.
   Desde su celular, averigüe qué licencia le corresponde y presente la solicitud". Use los datos
   ficticios de prueba del entorno de demostración; nunca los datos reales de la persona.
3. **Cronómetro**: anote el tiempo desde que abre el portal hasta que ve el comprobante. EQ-05 pide 15
   minutos o menos para el 90 % de las personas.
4. **Al terminar**, la persona responde el cuestionario (Google Forms o papel) sin que usted le explique
   las preguntas.
5. **No guarde** nombres, documentos ni celulares de los participantes: use "Persona 1" a "Persona 5".

## Las 10 afirmaciones (1 = totalmente en desacuerdo, 5 = totalmente de acuerdo)

1. Creo que me gustaría usar este sistema con frecuencia.
2. Encontré el sistema innecesariamente complicado.
3. Pensé que el sistema era fácil de usar.
4. Creo que necesitaría ayuda de una persona con conocimientos técnicos para usar este sistema.
5. Las funciones del sistema están bien integradas.
6. Pensé que había demasiadas incoherencias en el sistema.
7. Imagino que la mayoría de las personas aprendería a usar este sistema muy rápido.
8. Encontré el sistema muy difícil de usar.
9. Me sentí muy seguro(a) usando el sistema.
10. Necesité aprender muchas cosas antes de poder usar el sistema.

## Cómo calcular el puntaje

Para cada persona:

- en las afirmaciones **impares** (1, 3, 5, 7 y 9): respuesta − 1;
- en las **pares** (2, 4, 6, 8 y 10): 5 − respuesta;
- se suman los 10 valores (de 0 a 40) y se multiplican por **2.5**.

El resultado del sistema es el **promedio** de las 5 personas.

Ejemplo: con las respuestas 4, 2, 5, 1, 4, 2, 4, 1, 4, 2, la cuenta queda así:

- impares: 3 + 4 + 3 + 3 + 3 = 16;
- pares: 3 + 4 + 3 + 4 + 3 = 17;
- total: (16 + 17) × 2.5 = **82.5**.
